# Adaptive Learning System (Syniq compulsory)

## Cycle

**Observe** → **Extract lesson** → **Store** → **Apply**

## What to learn

- User preferences (brevity, depth, stack choices)
- Syniq skill combinations that worked
- Repo-specific pitfalls
- Corrections the user made

## Storage

Merge into workspace memory files when allowed; otherwise keep a concise session ledger.

## Apply

Start each turn by recalling top 3 active lessons. Drop lessons that contradict explicit new instructions.

Do not re-learn the same mistake twice in one session.
