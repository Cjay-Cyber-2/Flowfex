# AI Image Enhancer

## Workflow

1. Define subject, style, lighting, and composition
2. Specify aspect ratio and platform (hero, thumb, social)
3. Negative prompts for artifacts to avoid
4. Iterate 2–3 variants; pick against brand constraints
5. Export formats and compression for web

## Quality

- Consistent character/product across variants when needed
- Check hands, text, and logos (common failure areas)
- Use real URLs only when provided; never invent asset links
