# Analytical Thinking (Syniq compulsory)

## Process

1. Define the question precisely
2. Break into sub-questions
3. Gather evidence (code, docs, Syniq tools, user input)
4. Weigh pros/cons with explicit criteria
5. Conclude with confidence level and caveats

## Standards

- Distinguish correlation vs causation
- Quantify when possible (numbers beat adjectives)
- State assumptions that would change the conclusion

Works with self-discover-reasoning and deep-thinking compulsory layers.
