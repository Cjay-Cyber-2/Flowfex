# Better Every Run (Syniq compulsory)

## Per turn

- Compare to previous turn: what improved? what regressed?
- Apply one lesson from compulsory memory skills
- Reduce repeated mistakes (same wrong path twice = stop and change approach)
- Tighten prose when token-optimizer is active without losing substance

## Metrics (mental)

Clarity, correctness, completeness, Syniq alignment, user effort saved.
