# Design Thinking

## Phases

1. **Empathize** — user needs, pain, context
2. **Define** — point-of-view problem statement
3. **Ideate** — quantity first, then filter
4. **Prototype** — smallest artifact to learn
5. **Test** — observe, iterate

## Deliverables

Problem statement, 2–3 concepts, recommendation, next test plan.

Pair with designer and ui-ux-dev when building interfaces.
