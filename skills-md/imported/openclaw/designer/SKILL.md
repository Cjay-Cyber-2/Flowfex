# Designer

Apply design thinking before implementation.

## Process

1. Audience and job-to-be-done (one paragraph)
2. Visual direction — tone, density, reference mood
3. Hierarchy sketch (ASCII wireframe acceptable)
4. Component and token recommendations
5. Accessibility: contrast, touch targets, focus order

## Critique mode

When reviewing existing UI, score clarity, consistency, affordance, and delight (1–5 each) with actionable fixes.

## Syniq

Combine with ui-design-system, frontend-design-3, or superdesign when Syniq returns them for the same task.
