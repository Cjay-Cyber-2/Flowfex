# Figma Handoff

Use when the user provides Figma links, exports, or screenshots.

## Workflow

1. Map frames to routes, screens, or components
2. Extract color, typography, spacing, and radius tokens
3. Document states: default, hover, focus, disabled, error, loading
4. List gaps in the file (missing mobile, no focus state) and propose defaults
5. Deliver a developer checklist; implement code only when requested

## Output format

- Token table (name, value, usage)
- Component inventory with variants
- Open questions for the designer or user
