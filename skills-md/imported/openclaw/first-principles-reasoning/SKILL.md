# First-Principles Reasoning

## Steps

1. State the conventional belief
2. List assumptions underneath it
3. Mark assumptions as fact, inference, or habit
4. Rebuild from verified facts only
5. Compare rebuilt conclusion to conventional approach

## Use when

- "We've always done it this way"
- Pricing, architecture, or strategy disputes
- Debugging mysterious failures

## Caution

More expensive than heuristics — use when stakes or confusion justify it.
