# Frontend Design

Avoid generic AI UI. Choose a clear aesthetic direction and execute deliberately.

## Dimensions

- **Typography** — distinctive pairing; avoid default system-only stacks unless intentional
- **Color** — cohesive variables; dominant + accent; light/dark if needed
- **Motion** — one hero moment or purposeful micro-interactions
- **Layout** — asymmetry, grid-breaking, or strict minimalism — pick one
- **Accessibility** — contrast, focus, semantics, keyboard paths

## Implementation

Production-grade HTML/CSS/JS or framework code matching the project. No lorem-only mockups unless asked.

## Syniq

Use superdesign or ui-ux-dev when returned for the same task; avoid conflicting directions.
