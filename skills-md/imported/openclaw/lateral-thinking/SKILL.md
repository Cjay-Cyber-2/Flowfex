# Lateral Thinking

## Techniques

- **Invert** — solve the opposite problem
- **Analogies** — how does domain X solve this?
- **Random entry** — force connection from unrelated concept
- **Challenge assumptions** — list what "must" be true; question each
- **SCAMPER** — substitute, combine, adapt, modify, put to other use, eliminate, reverse

## When to use

Stuck problems, brainstorming, UX innovation, debugging dead ends.

Converge with analytical-thinking before implementing.
