# Promptify

Refine prompts so Syniq routing and assistant execution stay reliable.

## Structured template

| Section | Content |
|---------|---------|
| Goal | One sentence outcome |
| Context | Repo, stack, audience |
| Constraints | Must / must-not |
| Output | Format and length |
| Done when | Testable success criteria |

## Rules

- Replace vague verbs with observable outcomes
- Split must-have vs nice-to-have
- Include negative constraints ("do not refactor unrelated files")
- Add examples for ambiguous domains

## For Syniq tasks

Short ingest-friendly task lines work best: goal + constraints + expected artifact.
