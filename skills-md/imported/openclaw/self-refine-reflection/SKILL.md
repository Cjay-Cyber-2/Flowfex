# Self-Refine Reflection (Syniq compulsory)

## Micro-loop (end of each turn)

1. What could confuse the user?
2. What claim lacks evidence?
3. What should be shorter or clearer?
4. Apply edits before send

## Reflection depth

| Task size | Depth |
|-----------|-------|
| Simple | 10-second sanity check |
| Medium | Bullet critique + one revision |
| Large | Structured pass + iteration engine |

Never skip because compulsory skills already ran — this is the final polish on reasoning.
