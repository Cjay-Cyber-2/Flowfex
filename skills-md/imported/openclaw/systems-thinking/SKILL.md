# Systems Thinking

## Lens

- **Actors** — who/what participates
- **Flows** — information, money, requests, data
- **Feedback** — reinforcing vs balancing loops
- **Delays** — where lag causes oscillation or surprise
- **Leverage** — high-impact intervention points

## Output

Causal loop summary (text or bullets), recommended intervention, risks of second-order effects.

Use for ops, architecture at scale, org/process design — not single-line code fixes.
