# UI Final Polish

Run before calling UI work complete.

## Checklist

- Spacing rhythm consistent (4/8px scale)
- Typography hierarchy clear
- Hover/focus/active states present
- Loading and empty states styled
- Responsive breakpoints verified
- No layout shift on interaction
- Reduced motion respected when applicable
