# UI/UX Dev

Bridge user experience and implementation.

## Workflow

1. Clarify primary user flow and edge cases
2. Wireframe critical steps (ASCII or structured list)
3. Define breakpoints and component breakdown
4. Implement accessible markup and styles
5. Heuristic pass: visibility, feedback, error recovery, consistency

## Usability checklist

- [ ] Obvious primary action per screen
- [ ] Errors explain how to fix
- [ ] Loading and empty states exist
- [ ] Touch targets ≥ 44px where applicable
- [ ] Keyboard navigable

## Deliverable

Working UI plus short UX notes on trade-offs and follow-ups.
