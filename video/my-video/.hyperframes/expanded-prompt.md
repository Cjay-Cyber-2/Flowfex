# Flowfex Architecture Reel

Style block:
- Palette: `#080c10`, `#111820`, `#20303a`, `#00d4aa`, `#7ffff0`, `#46bda9`, `#e8edf2`, `#8a96a3`
- Fonts: `Geist` for statements, `JetBrains Mono` for technical metadata, `Space Grotesk` for utility labels
- Mood: luminous void, premium systems UI, visible signal flow, technical but cinematic

Rhythm declaration:
- `SLAM-build-PEAK-prove-resolve`
- Duration target: ~20 seconds
- Transition family: medium-energy blur/zoom push, one consistent language across the piece

Global rules:
- Every scene carries a grid, glow field, and metadata accents
- Every decorative has ambient motion
- Use the same dark canvas across all scenes
- Avoid generic startup gradients and centered slide layouts

## Scene 1: What Flowfex Is

Concept:
Flowfex appears like a control surface waking up. The viewer should instantly understand that this is not a chat UI, but a visual AI orchestration system with signal moving through infrastructure.

Mood direction:
Editorial tech trailer. Calm confidence with a hard systems edge.

Depth layers:
- BG: radial glow, grid lattice, ghost word `ORCHESTRATE`
- MG: giant Flowfex wordmark, subtitle, architecture blurb
- FG: mode pills, scan labels, stat card

Animation choreography:
- Wordmark SLAMS in
- Subtitle GLIDES up
- Stat card LOCKS into place
- Mode pills CASCADE across the frame
- Grid BREATHES slowly

Transition out:
- Blur zoom push, `0.5s`, `power2.inOut`

## Scene 2: How Teams Use It

Concept:
The product fans out into the four connection modes. The viewer should feel that multiple entry points collapse into one orchestrated system.

Mood direction:
Diagrammatic, controlled, slightly ceremonial.

Depth layers:
- BG: orbit rings, center glow, diagonal field lines
- MG: prompt, sdk, link, and live cards around a center hub
- FG: connection beam, token labels, micro metadata

Animation choreography:
- Center hub PULSES on
- Cards ARRIVE from different edges
- Beam FIRES vertically
- Accent rules DRAW outward

Transition out:
- Directional push, `0.5s`, `power3.inOut`

## Scene 3: Repo Architecture

Concept:
The repository turns into a navigable system map. This beat explains how the codebase is partitioned: frontend, backend, orchestration, SDKs, skills, and shared contracts.

Mood direction:
Technical dossier, premium terminal, architectural blueprint without feeling dry.

Depth layers:
- BG: stacked ghost folders, matrix dots, glow panels
- MG: repo tree panel on the left, capability columns on the right
- FG: stack badges, file-count callouts, divider rules

Animation choreography:
- Repo tree TYPES on in chunks
- Columns STACK upward
- Badges SNAP into rows
- Dividers DRAW across the frame

Transition out:
- Blur push right-to-left, `0.5s`, `power2.inOut`

## Scene 4: Runtime Orchestration

Concept:
The architecture becomes alive. A request moves through planner, capability retrieval, plan selection, graph building, execution, and real-time socket delivery.

Mood direction:
Machine room energy. Precise, kinetic, legible.

Depth layers:
- BG: deep glow, graph grid, signal haze
- MG: node-and-edge execution graph
- FG: namespace pills, event log, state badges

Animation choreography:
- Lines DRAW
- Nodes IGNITE in order
- Signal orbs TRAVEL through edges
- Namespace pills CLICK on
- Event log COUNTS through stages

Transition out:
- Cinematic zoom-through, `0.6s`, `expo.inOut`

## Scene 5: Product Proof and Close

Concept:
The abstract architecture resolves into the actual Flowfex product. The viewer sees the real UI framed like a live console, while the left side distills the repo’s purpose and stack.

Mood direction:
Confident product payoff. Premium but not sentimental.

Depth layers:
- BG: stable glow field, registration marks, edge rules
- MG: screenshot device frame on the right, summary block on the left
- FG: callout chips, stack tags, closing footer

Animation choreography:
- Screenshot DRIFTS into frame
- Summary headline RISES in
- Callouts PIN onto the UI
- Stack tags CASCADE
- Final statement HOLDS, then FADES

Transition out:
- Final fade to black only

Recurring motifs:
- Teal signal lines
- JetBrains Mono metadata strips
- Grid and registration marks
- Soft bright accent bloom at key beats

Negative prompt:
- No purple
- No generic gradient text
- No centered empty title cards
- No web-scale typography
- No static architecture diagrams with no motion
