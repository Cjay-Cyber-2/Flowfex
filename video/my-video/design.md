# Brand Direction

Flowfex should feel like a premium orchestration console inside a luminous void: high-contrast, technical, precise, and alive with signal motion.

For this version, the motion direction is specifically Apple-style product film:
- restrained
- product-first
- slow and deliberate
- large type with generous spacing
- premium transitions instead of busy animation

# Palette

- Background: `#080c10`
- Deep panel: `#111820`
- Secondary panel: `#20303a`
- Primary accent: `#00d4aa`
- Bright accent: `#7ffff0`
- Secondary accent: `#46bda9`
- Primary text: `#e8edf2`
- Muted text: `#8a96a3`
- Warm utility accent: `#8a7040`

# Typography

- Display: `Geist`
- Technical/UI labels: `JetBrains Mono`
- Secondary utility text: `Space Grotesk`

# Motion

- Primary motion language: signal propagation, path illumination, orchestration beams, pressure-release blooms
- Primary eases: `expo.out`, `power3.out`, `power2.inOut`
- Scene transitions: medium-energy blur/zoom transitions with directional push

# Shape

- Radius family: `8px`, `16px`, `20px`, `24px`
- Borders: thin luminous strokes, never heavy card chrome
- Shadows: dark depth plus restrained teal glow

# Do

- Fill frames with structural detail, grid traces, metadata, and active system texture
- Keep the accent visible and purposeful
- Anchor layouts to edges and use split-frame composition
- Treat architecture as a moving system, not static documentation

# Avoid

- Purple or blue neon defaults
- Flat black backgrounds with no texture
- Centered floating slide-deck layouts
- Generic SaaS gradients
- Warm playful motion that contradicts the product's control-surface feel
